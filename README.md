## 🛰️ SYSTEM ARCHITECTURE OVERVIEW

Project Aegis is a zero-dependency, framework-less single-page application (SPA) engineered with vanilla JavaScript, HTML5 Canvas, Web Audio API, and Netlify Edge Functions. It delivers tactile retro-futuristic telemetry intake while cataloging mortality vectors into a headless database via serverless Google Apps Script webhooks.
